## 开始使用

1. 准备语音引擎：推荐豆包语音（火山引擎 API Key）；也可用阿里云百炼、本机 OpenLess（开启远程输入），或闪电说等听写软件。全新安装时配置向导会带你完成，见下方“语音引擎与配置向导”。
2. 解压完整发布 ZIP，双击 Install.cmd 安装；从桌面「点声 DotVoice」打开。也可直接运行 DotVoice/DotVoice.exe 使用便携版。
3. 插入接收器、打开笔开关。
4. 在“设备”选择倍思或汉王，切换前先暂停。汉王另选“按住说话”或“单击切换”。
5. 在“语音”点击“启用语音输入”，等待就绪，将光标放进目标编辑框。
6. 倍思按住录音键说话、松开结束；或短按开始、再次短按结束。汉王按所选模式使用语音键。
7. 等待文字输入完成再开始下一段，保留目标编辑框焦点。

程序不自动发送、不注入回车、不重复粘贴结果。飞鼠移动、翻页由系统继续处理（点击与抓起见下方“按键”），激光照常。没有刷固件、更换驱动或恢复原厂翻译/聚光灯。

初次在“设置 → 安全测试框”核对输入位置和 Return 次数。备用手动开始有三秒切换光标时间，但不能代替笔的拾音开关。人工语音验收等本人准备好后再开始。

## 语音引擎与配置向导

“设置 → 语音引擎”决定由谁把声音变成文字。四张卡片里标着“正在使用”的是当前引擎；点卡片只是打开它的设置，按“使用 …”才会切换，所以看一眼别的引擎不会打断正在用的配置。录音或识别进行中不能切换（会提示等本段结束）；空闲时切换会先暂停语音、换引擎、再自动启用。已有的安装保持 OpenLess 不变。

- **豆包语音（推荐）**：火山引擎大模型流式语音识别，边说边出字，松开约半秒定稿，文字由点声直接输入到光标处。新版控制台填 API Key；旧版控制台填 App ID + Access Token。资源（Resource ID）要和控制台开通的服务一致：流式语音识别模型 2.0 小时版 `volc.seedasr.sauc.duration`（默认）或并发版 `volc.seedasr.sauc.concurrent`；“高级”里可换接口（默认 `bigmodel_async` 优化版）。
- **阿里云百炼**：Fun-ASR 实时识别（默认）或 Paraformer v2，地域北京（默认）或新加坡；两个地域的 API Key 不通用。Key 在百炼控制台的“API Key”页面创建。
- **润色（可选，豆包和百炼共用）**：原文（不调用大模型，最快）、轻度润色（去口头禅、补标点、不改原意）或自定义提示词；接任何 OpenAI 兼容接口（Base URL 通常以 `/v1` 结尾，公网必须 https）。润色失败时输入识别原文并提示。
- **OpenLess**：经它的“远程输入”识别，识别服务、润色风格和词典沿用 OpenLess 自己的设置；设置页显示是否安装、运行、远程输入是否开启。点声只读取配对码，不修改 OpenLess 的任何文件。注意 OpenLess 的远程输入会在局域网监听（有 6 位配对码保护），点声只连接本机 127.0.0.1。原文极速落字只对 OpenLess 生效。
- **其他语音软件（实验）**：热键桥接闪电说、Typeless、豆包输入法、微信语音输入、Windows 语音输入等：按 ⑥ 时点声替你按下它的快捷键，它自己收音、自己输入文字（点声看不到文字，完成后显示“已交给 …”）。检测到的软件排在前面；快捷键可录制或手动输入（含 Win 的组合请手动输入，例如 Ctrl+Win）；麦克风提示里写着笔的实际麦克风名，要在那个软件里选它。限制：管理员权限窗口里无效；按下后稍等半拍再开口；不能记笔记（笔记模式下会提示改用豆包 / 百炼 / OpenLess）；闪电说和微信默认都用 Ctrl + Win，同时运行会冲突。

每个引擎的“测试连接”只在你点按时发一小段静音或一条测试文字，结果直接显示在按钮旁。API Key 用 Windows 数据保护（DPAPI）加密保存在 runtime/secrets.json，只有这台电脑的这个 Windows 用户能解开；界面只显示“••••abcd”，密钥不会出现在 prefs.json、status.json、日志或界面数据里。选豆包或百炼时录音会实时发给对应云服务识别。

**配置向导**：全新安装第一次打开时出现（已有安装不会自动出现；随时可在“设置 → 语音引擎 → 重新运行配置向导”或“通用 → 配置向导”打开）。四步：① 设备——检测接收器、对着笔说话看麦克风电平、按一下 ⑥ 打勾；② 语音引擎——推荐豆包语音，可当场填 Key 并测试，也可选百炼、已安装的 OpenLess 或检测到的听写软件，或跳过；③ 试一句——按住 ⑥ 说一句，结果只显示在向导里，不会输入到别的窗口或存成笔记（热键桥接时文字由对方软件输入到向导里的输入框）；④ 完成——按键速查。向导打开期间每一段录音都是试说；关闭后自动恢复正常。

## 按键（倍思 BS-OH085）

- **⑥ 录音**：按住说话、松开结束；或短按开始、再短按结束。
- **⑦ 翻译键**：长按在 输入 → 笔记 → 演示 之间循环；短按记闪念笔记（第一下开始，第二下保存）。
- **⑤ 飞鼠键**：按住移动光标。输入、笔记模式下单击 = 鼠标左键，双击 = 双击（第一下立即点击，不等第二下）；演示模式下按住使用激光等工具，双击换工具，单击不做任何事。
- **③④ 短按**：任何模式下都是翻页，不会因为刚用过飞鼠就变成鼠标键。
- **③ 长按**：输入、笔记模式下“抓起”（按住左键），按住 ⑤ 移动去框选、拖动，再按一下 ③（短按、长按都行）放下；不需要先用飞鼠。笔同时发出的 Shift+F5、Win 和 Enter 会被拦下；20 秒不用飞鼠自动放下。演示模式下保持原样（开始放映）。
- **④ 长按**：输入、笔记模式下 = 鼠标右键（默认即可用，实测键码 6D，不必再录制）。笔同时发出的 B（PowerPoint 黑屏键）在普通窗口里会被拦下，不会在编辑框里打出 b；演示模式下和 PowerPoint / WPS 放映时保持原样（黑屏）。
- **按住 ⑤ + 音量 + / −**：上下滚动。按一下滚一段（约 9 行），按住超过半秒持续滚动；演示模式用放大镜时改为放大 / 缩小。音量键发的是笔自己的键码（实测 78 / 79），不经过键盘，所以电脑键盘上的音量键不受影响；不按 ⑤ 时音量键保持原功能。
- **⑧ 标注键**：按住 = Ctrl，配合单击 ⑤ 多选；演示模式下按住画标注、短按撤销。
- **② 激光键**：演示模式下按一下常亮数码激光，再按一下关闭。

笔的报文一次只带一个键码，两个键同时按并不可靠，所以没有其他组合键，也没有“用过飞鼠后几秒内”的隐藏时间窗口；唯一的组合是按住 ⑤ 时按音量键滚动。PowerPoint / WPS 全屏放映时（“放映时保持原样”开启）不点击、不抓起、不弹右键菜单、不滚动（放大镜调倍数除外）。这些键都可在“设置 → 飞鼠”重新录制（录音量键时可以先按住 ⑤，⑤ 本身不会被录下）或恢复默认。

## Tidepool OS

设备页查看接收器、链路与语音状态。统一控制提供“使用 Tidepool”“暂停接收”“取消本段”和 USB 屏幕唤醒/休眠。不另开串口、UDP 端口或音频转发连接。

控制接入后，启用翻页笔先暂停 Tidepool 接收；使用 Tidepool 先确认翻页笔麦克风/HID 完全释放。暂停同时阻止 USB/Wi-Fi 新会话并取消当前会话。界面不替用户开始 Tidepool 录音。

屏幕指令只在 USB 已连接时即时执行，有超时，不缓存到重连后。固件没有关联命令的状态确认；指令交给接收器不等于屏幕变化已验证。电量尚未上报电脑，显示“未上报”。

旧接收器没有控制 API 时按钮禁用，说明需更新。进程运行不等于设备在线，不用旧日志伪造在线状态。升级候选和说明在 integrations/tidepool。退出点声不会结束原接收器。

## 电量与续航

倍思已核实原厂电量字段：接收器 HID 输入报告的第 4 个字节。收到报告时更新百分比与时间，暂停状态也可更新；没有新报告时显示上次上报，不伪装成实时采样。首次观察到 100% 自动开始一轮记录，降至 10% 完成观察，再次充到 100% 保留上一轮。10% 是本软件的观察终点，不是已验证的固件低电量报警。PV60 尚无实机，电量协议待验证。

录音时长按实际传入 OpenLess 的 PCM 样本数统计，包含停顿；说话时长由本地 WebRTC VAD 估计，不是逐字对齐，噪声可能影响结果。默认不保存音频（调试录音见“数据、异常与升级”），仅保存电量和时长数字。历史版本没有采样统计的录音不会倒算。详见 design/BATTERY-PROTOCOL.md。

软件退出后的使用、激光/飞鼠耗电无法完整观测，历史日历跨度不等于剩余续航。不能用 300mAh 直接算天数。Tidepool 使用时间不混入翻页笔统计。

## 界面与效率

参考 Oil UI「应声」的文字上方单线节奏，独立实现细声线。聆听时由真实音量驱动，识别时显示等待状态，结果文字与细线逐步呈现。线条也不是音高、声纹身份或逐词时间戳。四态预览明确使用模拟数据，不接麦克风。

录音中的实时文字只取可靠来源：OpenLess 转发的实时文字，或内置云端引擎的流式结果（与最终结果同一个引擎）。本机离线预览模型（0.8 起）常有错字，默认不显示：胶囊和主窗口只显示声线与计时，说完显示定稿文字。需要时在“设置 → 语音识别 → 显示本机预览文字（可能不准）”打开。这个开关和“原文极速落字”都关闭时，本机模型不加载、不运行。

待机无动画循环，活动绘制上限30fps，隐藏/最小化/减少动态时停绘。启用后持续采集所选麦克风，保留句首缓冲；仅录音时传给 OpenLess。暂停释放电脑麦克风。PV60 暂停停止保活，但无验证过的固件关麦指令，不保证笔耗电降为零。

## 数据、异常与升级

适配器不保存录音/转写历史；窗口最近结果只在内存。OpenLess 自身云端服务和历史设置保持原样。不是独立离线识别器。

**调试录音（默认关闭）**：轻声识别不准时，可在“设置 → 语音识别”打开“保存最近 3 段录音用于调试（仅本机，24 小时后自动删除）”。之后每段录音在 runtime\diagnostics 留下三份文件：`时间-raw.wav`（笔的麦克风原始声音）、`时间-sent.wav`（经过气声处理后实际发给语音引擎的声音）和 `时间.json`（气声处理的电平、底噪、增益与判定，引擎、模式和识别结果）。只保留最近 3 段，超过 24 小时的在启动时、每小时和每次新录音时删除；关闭后不再保存。文件只在这台电脑上，点声不会上传；需要时用开关旁的“打开文件夹”取出。

配对码读取 %APPDATA%\com.openless.app\remote-input-pin.txt，不输出。默认读取 OpenLess preferences.json 的远程输入端口（缺失时 8443），每次重连重读端口和配对码，只允许本机 WSS。保持启用时连接失败每 5 秒重试；协议版本不兼容会明确报错，不能保证未来所有版本无需适配。Tidepool控制凭据不进入页面或发布包。

安装到 %LOCALAPPDATA%\Programs\DotVoice，并登记 Windows「已安装的应用」、桌面和开始菜单快捷方式。安装版统计/偏好独立放在 %LOCALAPPDATA%\DotVoice\runtime；便携版仍在 EXE 同级 runtime。卸载保留用户记录，只删除清单中的程序文件。升级会保留旧程序目录作为备份。默认不开机自启。

**兼容管理员权限窗口（默认关闭）**：以管理员身份运行的窗口（例如 Androws.exe 里的红果短剧）会被 Windows（UIPI）拦截普通程序的模拟点击、滚动、文字输入和热键；点声发现前台窗口是这种情况时照样尝试，但每个窗口提示一次，云端引擎/极速落字没能输入的文字复制到剪贴板（Ctrl+V 粘贴）并保留在本次结果里。在“设置 → 通用”开启后，确认一次 UAC，点声登记计划任务“DotVoice (管理员)”（登录时以管理员身份 --hidden 启动，最高权限，仅当前用户），并以管理员身份重启；之后从快捷方式启动也会交给该任务（不再弹 UAC）。关闭则删除任务并以普通权限重启。这是点声唯一的开机启动项；卸载会删除它（可能需要确认一次管理员权限）。

关闭窗口会留在托盘，保持当前启用/暂停状态；再次启动快捷方式或双击托盘恢复窗口。右键托盘可启用、暂停、彻底退出；退出释放麦克风，不结束 OpenLess 或 Tidepool 接收器。托盘异常时关闭窗口直接退出并显示提示。

启动异常记录在 %LOCALAPPDATA%\DotVoice\startup-error.log。0.3.0 的 ZIP 漏打了 Python.NET runtime 依赖，导致解压后无法启动；0.4.0 修复，并以最终 ZIP 解压后自检为验收依据。请使用新版入口。

掉线取消并清空本段，恢复后等新操作，不重放旧音频；忙时按键不补录。单段最长十分钟，识别等待两分钟。OpenLess 已插入文字不会被撤销。HID关闭失败禁止创建第二会话。

绿色代表连接就绪，红色代表暂停或异常，始终配合文字。设备绿点只表示接收器存在，不证明笔已唤醒。托盘和正在运行的任务栏按钮同步状态；关闭窗口隐藏到托盘后，固定的快捷方式不能持续显示任务栏叠加标记。

0.5 修复充电后语音键失效：旧代码误将电量 0x4c 写死为按键报文的一部分，充满变为 0x64 后报告被丢弃。当前 OpenLess 2.0.0-Beta.4 认证已验证。

## 开发与发布

0.7 起分成两个进程：`shell/` 是 Tauri 2 外壳（React + Motion 界面、托盘、单实例、全局快捷键、灵动胶囊窗口）；`core_main.py` + `bridge/` 是 Python 核心（HID、麦克风、OpenLess、笔记、续航）。外壳经 stdin/stdout 的 JSON 行协议启动并控制核心，不开端口；外壳退出时核心读到 EOF 自行释放麦克风与 HID。

Windows 10/11 x64、Python 3.12、Node 24 + pnpm、Rust（MSVC）、WebView2：

```powershell
python -m venv .venv
.venv/Scripts/python.exe -m pip install -r requirements-build.txt
.venv/Scripts/python.exe -m unittest discover -s tests -v
pnpm --dir shell install
pnpm --dir shell test; pnpm --dir shell typecheck; pnpm --dir shell build; pnpm --dir shell qa
pnpm --dir shell tauri dev          # 开发：外壳直接运行 .venv 中的 core_main.py
.\build.ps1                         # 发布：dist/0.11.4/DotVoice/{DotVoice.exe, core/, models/}
dist\0.11.4\DotVoice\DotVoice.exe --smoke
dist\0.11.4\DotVoice\core\dotvoice-core.exe --check-preview   # 本机预览模型能否加载
.venv/Scripts/python.exe tools/package_release.py
```

发布用的 DotVoice.exe 必须由 `pnpm tauri build`（build.ps1 已这样做）生成：单独 `cargo build --release` 不会嵌入页面，窗口会是空白的。便携版必须保留整个 core 目录（含 core/_internal）和 models 目录（实时预览模型，约 25 MB；缺失时只是没有预览）。`--smoke` 不打开麦克风/HID，检查核心握手、胶囊不抢焦点与可点穿、托盘、关闭留在后台、二次启动恢复与退出，结果写入 runtime/smoke/runtime/ui-smoke.json；截图与临时数据放在 %TEMP%\dotvoice-smoke-<pid>，运行结束即删除。`pnpm --dir shell qa` 用浏览器模拟核心检查各页面与胶囊状态，截图在 design/qa-0.8。实机按键探测：`.venv/Scripts/python.exe tools/probe_keys.py --audio`（只读，麦克风只记录音量数字）。旧的 pywebview 外壳保存在 backups/dotvoice-0.6-before-tauri-*.zip。

## 0.9.2：按键实测后修正（⑤ 双击、③ 长按框选、蓝牙音箱第一声、空录音）

依据用户实际操作留下的按键记录（runtime/key-log.txt）：

- **⑤ 双击发 71**：固件自己识别双击，发厂商码 71（有时连发两次），不会发两组 72/73，所以原来按时间判断双击永远不会触发。演示模式下收到 71 就切换到下一个工具（激光 → 聚光灯 → 放大镜 → 只用飞鼠），0.6 秒内连续的 71 只算一次。
- **③ 长按 = 按住左键**：长按 ③ 时，笔会在长按生效后发 6B，一直保持到松开（松开发 00），同时还会发 Shift+F5、一次 Win 键和一个多余的 Enter 松开。按住 ⑤ 使用飞鼠时（以及松开后的保持时间内），长按 ③ 就是按住鼠标左键，移动飞鼠框选或拖动，松开 ③ 结束；那几个附带按键会被拦下，所以不会开始放映，也不会弹出开始菜单。PowerPoint / WPS 放映时保持原样。快速按两下 ③ 锁住左键的办法仍然可用。
- **第一声提示音听不到**：输出设备是蓝牙音箱（Beosound A1）。它安静几秒后会休眠，唤醒要 0.5–1 秒，正好吞掉单独一声短提示音，而第二声趁它没睡就能听到。播放记录显示每次都“已播放”，证实了这一点。现在点声会保持一个听不见的循环音频流（±1 级抖动，由驱动自己循环，几乎不占 CPU），并每 10 分钟重开一次以跟随默认输出设备。设置里可以关闭。
- **空录音不再记成笔记**：录音结束时，如果超过 0.6 秒却只检测到不到 0.25 秒的人声，本段直接取消，不发给 OpenLess，所以 OpenLess 润色模型不会对着空文本回一段“转写内容为空……”，既不会被输入，也不会被保存。另外，笔记模式还会拦下这类“内容为空”的回复。胶囊会显示“没听到说话”。
- **本机预览用上 SenseVoice**：已经找到你在 OpenLess 里下载的 SenseVoice small，0.9.2 启动后会自动用它重读当前这句：更准、带标点、数字转阿拉伯数字。模型在启动后预先加载，不会拖慢第一句。修正了精修文字与流式尾巴重复几个字的问题，句中不再出现多余的句号。
- **合并提醒**：点声每 12 小时匿名查询一次 GitHub 公开接口，看 OpenLess 是否已合并 PR #1147 并发布新版。有了就在主窗口顶部提示升级 OpenLess；如果点声发现已经能收到 OpenLess 的实时文字，就停止查询。请求不带任何个人信息。

## 0.9.3：单击与双击 ⑤ 分开、长按 ③ 抓取、胶囊细节、其他设备卡片

- **⑤ 单击不再换工具**：新的按键记录表明，轻点一下 ⑤ 笔就会发一个 71，双击是两个 71（相隔 0.2–0.6 秒），按住才是 72/73。现在只有 0.55 秒内连续两个 71 才算双击，用来切换演示工具；单击不做任何事。原来“快速按住两次 ⑤ 也算双击”的旧规则一并删除，免得误切。
- **长按 ③ = 抓起，再按 ③ = 放下**：记录显示，长按 ③ 时如果按下 ⑤，笔会在约 15 ms 后重发 6B，松开时还可能插入 00 或 6A，所以“两个键一起按住拖动”很容易中途断掉。现在改成开关式：使用飞鼠时长按 ③ 抓起（左键按住），按住 ⑤ 随意移动去框选或拖动文件（两个键不必同时按），再按一下 ③（短按、长按都行）放下。抓起后即使过了很久，按 ③ 也会放下，不会变成翻页。笔紧跟 ⑤ 重发的 6B 会被忽略。胶囊会一直提示“已按住左键”。
- **胶囊玻璃边缘**：折射边原来是 5 px 的硬边环，暗背景上会显出一圈生硬的亮边；现在把它的内边缘羽化，并降低亮度，主体模糊加大到 18 px。
- **“正在听”居中**：还没说话时，提示居中显示、不加左侧渐隐；开始说话后才按右对齐、左侧渐隐滚动显示。
- **左下角显示其他设备**：检测到另一支已连接的笔（倍思 / PV60），或 Tidepool 在线时，左下角状态卡上方会出现对应的小卡片，点击进入设备页；没有就不显示。
- **空结果显示**：OpenLess 返回空白文字时，首页显示“本次没有识别到文字”，空格和换行不再画声线（原来会出现像“✓”“•”的小记号）。

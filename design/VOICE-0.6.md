# 点声 0.6 视觉与数据边界

参考原件：应声 https://ui.oiloil.org/works/voice/live/index.html 。2026-10-03 下载 index.html、screens.html、assets/voice.js、assets/voice.css，SHA256 见 references/oil-voice-live/source-manifest.json。四个状态共用一套 JS/CSS，不是四个独立项目。原示例使用预设文案/声调/实体，不采集实际音频；项目中的声幅由真实 RMS 驱动。

1. 等待：安静、静态的短曲线，不持续唤醒 Canvas。
2. 聆听：归一化 RMS 包络、连续平滑节点、圆头变宽线；100ms 实测输入，最多 30fps 绘制，静音和断流为零。
3. 拆分：服务返回真实文字后，在本地分词选出的词上形成括号。未拿到文字时只显示等待，不填预设词。分词不等同语义推理，不虚构人名、时间或论文结论。
4. 结果：显示完整文字，保留本次完整音量包络，按行分配轨迹；此处不是精确字音对齐。

浮动声笺使用相同 VoiceArt 渲染器，顶部细小状态标记、中央 52px 波形空间、底部两行文字与耗时。不接收键盘焦点、不注入键盘、不另建音频采集。暂停隐藏，结果 12 秒后隐藏，闲置无持续重绘。用户关闭单次浮窗不暂停录音，设置可关闭功能。

笔记是本地持久化功能：独立 JSON 原子写入，一条录音一条笔记；source 是服务返回稿，text 是可编辑整理稿。无额外 AI 服务，也无自动论文创新判断。

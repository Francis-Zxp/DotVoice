# 点声 / DotVoice：命名评估

> 结论先行：**中文名「点声」保留**，它和标识里那个圆点是同一个想法，改名的收益小于代价。**英文名 DotVoice 偏弱**，建议以后另起一个英文名，但本次不改代码，改之前先查商标。

## 1. 「点声」好在哪

| 维度 | 评价 |
| --- | --- |
| 一字多义，全都贴合产品 | **点** = 一个点（标识里的声点），= 按一下（笔上的录音键），= 指点（演示模式的激光笔、标注），= 一点点（轻、快）。**声** = 人声。合起来就是"按一下，就出声 / 出字"，正好是核心交互。 |
| 短、好读 | 两个字，diǎn shēng，三声转一声，先压后扬，念起来有"按下去再弹起来"的节奏。 |
| 能画出来 | 名字本身就给了视觉锚点：一个点。标识是靛蓝方块上的一笔「d」加一个圆点（0.10.1–0.10.3 是玫红方块，0.10.4 起改为靛蓝，0.11.3 起界面品牌色也随之统一为靛蓝），名字和图形互相解释。 |
| 气质 | 克制、好记、偏现代，不俗。 |

## 2. 「点声」的弱点

1. **"点"在口语里也有"点播 / 点单"的意思**（点歌、点菜），"点声"可能被读成"点一个声音"。
2. **和「电声」(diàn shēng) 读音接近**，后者是"电声乐器 / 电声乐队"，偏音响硬件，和高端软件的气质不同。
3. **只说了"声"，没说"字"**：用户要的结果是光标处的文字；笔记、演示两大能力也不在名字里。
4. **高端感中等**：它聪明、友好，但不"贵"。高端感主要得靠标识材质、动效和细节来撑，名字撑不了。

> 缓解办法（成本几乎为零）：固定搭配口号 **「一点即声，字落光标」**，第一次见到就能把"点"读对，也补上了"字"。

## 3. 英文名 DotVoice 的问题

- **和 Amazon Echo Dot（Alexa 语音音箱）联想很强**："Dot + Voice"几乎就是在描述它，有混淆风险，也显得像配件。
- **过于描述性**：两个通用词拼接，搜索结果拥挤，难建立独占认知，商标近似风险高。
- 好处：外国人一看就懂，和中文名逐字对应。

## 4. 备选名（3–5 个）

| 候选 | 含义与理由 | 风险 |
| --- | --- | --- |
| **落字 · Luozi** | "说完，字就落下"——直指结果；又和围棋的"落子"同音，带"落子无悔"的果断与智识感。 | 不直接出现"声"，需要标识和口号帮助；"落"字气质偏静。 |
| **言出 · Yanchu** | 取自"言出必行 / 言出法随"：话一出口就成真（成字）。自信、有分量，最"高端"。 | 语气偏大，可能显得夸张；双字词较常见，注册难度未知。 |
| **闻笔 · Wenbi** | "会听的笔"：直接对应倍思 / 汉王这类笔形硬件，古雅（博闻、闻声）。 | 现代汉语里"闻"首先是"嗅"，有被读成"闻一闻笔"的风险。 |
| **点声 + 新英文名 Tittle** | 中文不变。Tittle 是字母 i、j 上那个点的专名，"一个点 + 一笔"正是新标识；小众、可拥有、有设计感。 | 易与 title 混淆；英语里 tittle-tattle 有"闲话"的意思。 |
| **点声 + 新英文名 Dian** | 中文不变，英文直接用拼音"Dian"（像 Xiaomi、Oppo 那样）：短、独特，全球可读。 | 失去英文语义；需要配合标识与副标题（Dian · voice to cursor）。 |

## 5. 建议

1. **保留「点声」**。它和新标识、和"按一下就说"的交互是一回事；现有用户已经认得它，安装包、快捷方式、文档里也都是它。
2. **口号固定为「一点即声，字落光标」**，用在安装、关于页、启动和空状态里。
3. **英文名放到第二阶段**：优先考虑 **Dian**（风险最低）或 **Tittle**（设计感最强）。改之前先在国家知识产权局查第 9 类（软件）和第 42 类（软件服务）的近似商标，再检查域名和应用商店重名。
4. 本次**没有改动**任何代码里的名称、窗口标题、安装器或 exe 文件名。
